 Фінальний проєкт: Алгоритми та структури даних

 Опис проєкту

У межах фінального проєкту реалізовано сім завдань, присвячених основним алгоритмам і структурам даних мовою Python.

Проєкт охоплює роботу зі зв'язними списками, рекурсію, алгоритми пошуку найкоротших шляхів, бінарні купи, обходи дерев, жадібні алгоритми, динамічне програмування та метод Монте-Карло.

 Використані технології

- Python 3.9+
- Matplotlib — побудова графіків і візуалізація.
- NetworkX — створення та візуалізація графів.

 Структура проєкту

```text
goit-algo-fp/
├── task1_linked_list.py
├── task2_pythagoras_tree.py
├── task3_dijkstra.py
├── task4_heap_visualization.py
├── task5_tree_traversal.py
├── task6_greedy_dynamic.py
├── task7_monte_carlo.py
├── requirements.txt
├── README.md
└── .gitignore
```

 Завдання 1. Однозв'язний список

 `task1_linked_list.py`

Реалізовано клас однозв'язного списку та такі операції:

- Реверсування списку шляхом зміни посилань між вузлами.
- Сортування списку методом сортування злиттям (Merge Sort).
- Об'єднання двох відсортованих однозв'язних списків в один відсортований список.

Для перевірки реалізовано приклади використання кожної операції.

Завдання 2. Фрактал «Дерево Піфагора»

`task2_pythagoras_tree.py`

Реалізовано побудову фрактала «Дерево Піфагора» за допомогою рекурсії.

Особливості:

- Користувач самостійно задає глибину рекурсії.
- Кожен наступний рівень дерева створюється на основі двох дочірніх квадратів.
- Для побудови та відображення фрактала використовується Matplotlib.

Завдання 3. Алгоритм Дейкстри

 `task3_dijkstra.py`

Реалізовано алгоритм Дейкстри для пошуку найкоротших шляхів у зваженому графі.

Особливості:

- Для зберігання графа використовується список суміжності.
- Для вибору вершини з найменшою поточною відстанню використовується бінарна купа через модуль `heapq`.
- Обчислюються найкоротші відстані від початкової вершини до всіх інших вершин.
- Передбачено обробку вершин, до яких шлях відсутній.
- Алгоритм перевіряє наявність від'ємних ваг.

 Завдання 4. Візуалізація бінарної купи

 `task4_heap_visualization.py`

Реалізовано створення та візуалізацію бінарної мінімальної купи.

Особливості:

- Початковий список перетворюється на мінімальну купу за допомогою `heapq.heapify()`.
- На основі масиву купи будується бінарне дерево.
- Для візуалізації використовується бібліотека NetworkX та Matplotlib.

 Завдання 5. Обходи дерева: DFS і BFS

 `task5_tree_traversal.py`

Реалізовано два алгоритми обходу бінарного дерева:

- DFS (Depth-First Search) — обхід у глибину за допомогою стеку.
- BFS (Breadth-First Search) — обхід у ширину за допомогою черги.

Особливості:

- Обидва алгоритми реалізовані без використання рекурсії.
- Порядок відвідування вузлів виводиться в консоль.
- Процес обходу візуалізується покроково.
- Відвідані вузли змінюють колір відповідно до порядку обходу.

 Завдання 6. Жадібний алгоритм і динамічне програмування

 `task6_greedy_dynamic.py`

Реалізовано два підходи до вибору продуктів з урахуванням обмеженого бюджету.

Жадібний алгоритм:**

- Обчислюється співвідношення калорійності до вартості кожного продукту.
- Продукти сортуються за цим показником.
- Продукти додаються до набору, якщо не перевищується бюджет.

Динамічне програмування:**

- Використовується задача про рюкзак (0/1 Knapsack).
- Будується таблиця оптимальних значень для різних бюджетів.
- Визначається набір продуктів із максимальною калорійністю в межах бюджету.

Обидва результати виводяться для порівняння.

 Завдання 7. Метод Монте-Карло

 `task7_monte_carlo.py`

Реалізовано симуляцію кидання двох гральних кубиків за допомогою методу Монте-Карло.

Особливості:

- Виконується 100 000 випадкових кидків двох кубиків.
- Підраховується кількість випадінь кожної можливої суми від 2 до 12.
- Обчислюються експериментальні ймовірності.
- Розраховуються теоретичні ймовірності на основі 36 можливих комбінацій.
- Результати порівнюються у таблиці та на стовпчиковій діаграмі.

 Результати моделювання

Порівняння експериментальних і теоретичних ймовірностей:

| Сума кубиків | Монте-Карло | Теоретична ймовірність |
|:------------:|:-----------:|:----------------------:|
| 2            | 2.69%       | 2.78%                  |
| 3            | 5.56%       | 5.56%                  |
| 4            | 8.53%       | 8.33%                  |
| 5            | 11.04%      | 11.11%                 |
| 6            | 13.98%      | 13.89%                 |
| 7            | 16.58%      | 16.67%                 |
| 8            | 13.85%      | 13.89%                 |
| 9            | 11.02%      | 11.11%                 |
| 10           | 8.33%       | 8.33%                  |
| 11           | 5.70%       | 5.56%                  |
| 12           | 2.71%       | 2.78%                  |

 Висновки

Результати симуляції наближені до теоретичних значень і демонструють правильний розподіл ймовірностей для суми двох гральних кубиків.

Найбільшу ймовірність має сума 7, оскільки її можна отримати шістьма різними комбінаціями. Найменшу ймовірність мають суми 2 та 12 — для кожної існує лише одна комбінація.

Невеликі відхилення між експериментальними та теоретичними значеннями пояснюються випадковим характером моделювання. Зі збільшенням кількості експериментів результати зазвичай наближаються до теоретичних ймовірностей.
 
 Встановлення та запуск

 1. Клонування репозиторію

```bash
git clone https://github.com/Horbunov-Yurii/goit-algo-fp.git
```

 2. Перехід до папки проєкту

```bash
cd goit-algo-fp
```

 3. Встановлення залежностей

```bash
python3 -m pip install -r requirements.txt
```

 4. Запуск завдань

Кожне завдання запускається окремо:

```bash
python3 task1_linked_list.py
python3 task2_pythagoras_tree.py
python3 task3_dijkstra.py
python3 task4_heap_visualization.py
python3 task5_tree_traversal.py
python3 task6_greedy_dynamic.py
python3 task7_monte_carlo.py
```

Для завдань із графічною візуалізацією відкривається окреме вікно Matplotlib.
